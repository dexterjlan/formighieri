## DEV com token na sessão

1. **Configurações → Matrix (teste)** → homeserver + access token (Element → Avançado).
2. Envio **direto** na API Matrix (texto simples, rápido).

## DEV / prod sem token na tela

Usa o mesmo **Apps Script** que produção (`MATRIX_ACCESS_TOKEN` nas propriedades).
